## Key evidence

The off-the-shelf Rust crate `serde_jcs` 0.1 is not RFC 8785-conformant (code-point key order;
emits integers ≥ 2^53) — its hash differs from the reference for the same object. The canonical
scenarios include the discriminating cases; the Rust implementation must not rely on that crate
unverified.
