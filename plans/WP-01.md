## Rust readiness (for RUST_IMPLEMENTATION)

See `assurance/layers/01-feasibility-matrix.md`.
- **Canonicalizer.** `serde_jcs` 0.1 orders object members by code point, not UTF-16 code units, so
  it cannot be the canonicalizer unchanged.
- **Domain bound is not a serializer defect.** Emitting 2^53 is no RFC 8785 defect; Mneme's domain
  bound (G-025) is enforced by the SER-008 validator.
- **Decoding.** The structural JSON decode must defer numeric interpretation so that stage-1 errors
  outrank numeric ones. The witness is `{"a":1e400,"b":1,"b":2}`, which must give
  `value.duplicate_key`.
