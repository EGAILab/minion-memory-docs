## Open before the contract checkpoint (path C — Owner)

- **NF-010 residual** — ID lexical domain (IDs appear in package file names; Windows is case-insensitive).
- **NF-012** — does CORE-003's same-ID-same-version conflict rule bind every versioned core artifact?
- **NF-015** — timestamp representation and precision (G-016 caps integer timestamps at µs).
- **NF-022** — integer vs whole-number float (RFC 8785 cannot distinguish `1` and `1.0`).

## Key evidence

The off-the-shelf Rust crate `serde_jcs` 0.1 is not RFC 8785-conformant (code-point key order;
emits integers ≥ 2^53) — its hash differs from the reference for the same object. The canonical
scenarios include the discriminating cases; the Rust implementation must not rely on that crate
unverified.
