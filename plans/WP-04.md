# WP-04 — Layer 04: canonical history store

**Status:** `CONTRACT_DRAFT`. **Governance:** G-077…G-084 (`reference/governance/2026-10-11-owner-layer04-start.md`); G-013 (conflicting retry);
G-047, G-051 and G-054 (store-local cursor). **State:** `process/state/WP-04.yaml`.

## Scope (G-078)

| Requirement | Surface |
|---|---|
| PERS-005 | transactions and crash/restart behaviour |
| PERS-006 | at most one committed mutation per operation identity; a retry returns the original result |
| PERS-007 / PERS-008 | bounded since-boundary reads over gapless store positions (G-080); HistoryBoundary |
| PERS-012 | domain repository with append semantics only |
| PERS-014 | shared physical storage keeps profile identity explicit |
| PERS-015 | the single-writer assumption |
| HIST-008 | no semantic deduplication; only operation-identity idempotency |
| HIST-009 | the committed durability barrier that WP-04T consumes |

**Backend (G-079).** The contract is backend-neutral; PostgreSQL with one shared schema is the
reference backend, provisioned per G-081.

**Not in scope:** tiers, enrichment ordering, local-first and assets (WP-04T); checkpoints
(Layer 05).
